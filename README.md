# pdf2skill

将专业 PDF 文档（标准 / 指引 / 规范 / 手册）转化为可复用的 Skill 技能包，实现文档知识的结构化提取、资源文件编写、质量验证与打包分发。

https://mp.weixin.qq.com/s/cJjlVpiFACY36UmIKPj7KQ
https://skillhub.cn/user/user_b818ef37

## 它能做什么

把一份几十上百页的专业 PDF（工程造价指引、技术标准、操作手册、法规汇编、参数手册、财务模板），转化为 AI 智能体可直接加载使用的 Skill：

- **数据硬编码** — 指标/参数写入资源文件，AI 只调用，不凭记忆补数据
- **来源可溯源** — 每条数据标注资源文件名 + PDF 页码
- **计算透明** — 展示公式与中间结果，可手工复算
- **校验内嵌** — 互斥/优先/边界/约束规则写进 SKILL.md

## 工作流（7 个阶段）

1. **文档分析** — fitz + pdfplumber 双通道提取，输出 Skill 架构方案
2. **资源文件创建** — 按章节拆分结构化资源文件（P0 → P1 → P2 渐进交付）
3. **SKILL.md 编写** — 工作流 + 校验规则 + 资源目录
4. **质量验证** — 数据准确性（L1/L2/L3 三级抽样）+ 功能可用性（8 维度）
5. **使用说明与案例** — 案例 + FAQ + 数据溯源
6. **打包前检查复核** — 完整性/准确性/6 维度质量评估（D1~D6，加权 ≥ 4.0 才可发布）
7. **打包分发** — 生成 SkillHub 可上传的分发 zip 包

## 使用方法

1. 将 `SKILL.md` 放入你的智能体技能目录（如 WorkBuddy 的 `~/.workbuddy/skills/pdf2skill/`）
2. 对智能体说："把这份 PDF 转成 Skill"，并提供 PDF 路径与目标技能名
3. 按工作流阶段确认方案后自动推进

## 适用与不适用

| 适用 | 不适用 |
|------|--------|
| 工程造价指引、技术标准规范、操作手册/SOP | 小说/报告/演示文稿（无结构化数据） |
| 法律法规汇编、产品参数手册、财务测算模板 | 纯叙述性文档（无规则/参数） |
